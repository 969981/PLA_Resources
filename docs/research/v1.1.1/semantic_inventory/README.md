# PLA 1.1.1 — static semantic candidate inventory

This directory contains two analysis layers. Both are static Ghidra evidence; neither proves runtime/UI behavior.

## First pass

The original candidate inventory is a broad discovery index. Its string xrefs are attributed using exported function address intervals, so interval ownership is provisional.

- domain_string_xrefs.csv: domain keyword strings and direct references.
- domain_function_candidates.csv: ranked candidate functions by domain.
- selected_callgraph_edges.csv: direct call references adjacent to top-ranked candidates.
- rtti_vtable_typeinfo_symbols.csv: RTTI/vtable/typeinfo-like symbol names and xref counts.
- decompilation_failures.csv: unsuccessful or empty decompilation records.
- summary.json: counts, evidence scope and mapping caveats.

## Exact-body review

The review_v2 subdirectory is generated by reopening the restored Ghidra 12.2 project in read-only/no-analysis mode and exporting each function's exact body ranges. It then rebuilds caller ownership from those ranges and only accepts direct callees whose target equals a known function entry.

- review_v2/top_candidates.json: compact top candidates and direct neighbors for six business domains.
- review_v2/semantic_shortlist.csv: ranked shortlist.
- review_v2/semantic_string_xrefs.csv: string xrefs with exact source-function body ownership.
- review_v2/semantic_callgraph_edges.csv: aggregated direct calls touching the shortlist.
- review_v2/top_candidate_pseudocode.md: leading Ghidra C pseudocode excerpts.
- review_v2/summary.json: counts and validation results.

- pokedex_resource_manager.md: first static reconstruction of the Pokédex resource manager, table loaders, record post-processing and separate Pokédex view path.
- pokedex_function_annotations.json: evidence-graded provisional function names and unresolved links.
